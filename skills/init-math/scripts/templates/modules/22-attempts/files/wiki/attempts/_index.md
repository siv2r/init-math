# Lines of attack

One file per line of attack (`L<nnn>-<slug>.md`, format in [TEMPLATE.md](TEMPLATE.md)),
written through `bin/attempts`. This page is not a list: run `bin/attempts` for one line per
target, `bin/attempts --target <id>` for one target's lines, and
`bin/attempts --obstructions <id>` for what has already failed there. Reasoning:
[docs/discipline/attempt-loop.md](../../docs/discipline/attempt-loop.md).
