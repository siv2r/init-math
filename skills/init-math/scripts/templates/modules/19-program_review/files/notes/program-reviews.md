# Program reviews

The record of each program review: only the findings the owner accepted, the changes kept
or reverted, and what to watch before the next review. Drafts are not kept. Newest last.

Format of a section:

    ## YYYY-MM-DD — program review

    Findings accepted:
    - <finding> (evidence: <file:line, commit, or log row>)

    Goal answers: see notes/program-goals.md, YYYY-MM-DD.
    Changes kept / reverted: <list>
    To watch before the next review: <list>

A declined offer is recorded as one line, so the next offer waits a full interval:

    ## YYYY-MM-DD — offer declined

(No reviews yet.)
