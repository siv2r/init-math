# Concepts

Synthesized articles, one bounded idea each (a definition, a theorem and its proof idea, a
method, a construction). Written by us from the sources in [../raw/](../raw/_index.md):
synthesized, not copied.

- One file per idea, `<slug>.md`, starting with frontmatter: `title`, `sources` (the raw
  files it draws on), `updated` (date), `confidence` (high, medium or low, from the quality
  of the sources, with the reason on the same line), and a short `summary`.
- End each article with `## See also` (links to related articles, in both directions)
  and `## Sources` (links to the raw files).
- Add a row below for each article.
