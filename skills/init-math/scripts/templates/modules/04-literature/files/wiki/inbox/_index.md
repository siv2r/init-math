# Inbox

Sources someone wants read and that have not been ingested yet, one file each (any name
other than this one). Each file says what the source is and why it is here.

To work an item (the `ingest` skill): copy the source into [../raw/](../raw/_index.md),
synthesize what matters into an article in [../concepts/](../concepts/_index.md) (a reading
list in [../references/](../references/_index.md) may link it too, but does not replace the
article), add a line to [../log.md](../log.md), and delete the inbox note (never the raw copy). Do not experiment off a source
that is still in the inbox.
