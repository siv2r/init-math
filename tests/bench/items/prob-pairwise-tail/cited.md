- Markov's inequality (Durrett, Probability: Theory and Examples, 5th ed., Section 1.6): if Y >= 0 and a > 0, then P(Y >= a) <= E[Y] / a.
- Expectation of a product of independent variables (Durrett, 5th ed., Section 2.1): if X_1, ..., X_n are independent and either X_i >= 0 for all i or E|X_i| < infinity for all i, then E[X_1 ... X_n] = E[X_1] ... E[X_n]. Here X_1, ..., X_n are independent if P(X_1 in B_1, ..., X_n in B_n) = P(X_1 in B_1) ... P(X_n in B_n) for all Borel sets B_1, ..., B_n; Durrett, Section 2.1, gives an example of three events that are pairwise independent but not independent. Functions h_i(X_i) of independent variables are independent.
