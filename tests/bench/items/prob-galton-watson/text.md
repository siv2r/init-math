# Proof

Let xi denote a random variable with the offspring distribution, with mean mu and variance
sigma^2, and let F_n be the sigma-field generated by Z_0, ..., Z_n. Given F_n, the next
generation Z_(n+1) is a sum of Z_n independent copies of xi, independent of F_n. Hence

  E[Z_(n+1) | F_n] = mu Z_n,   E[Z_(n+1)^2 | F_n] = sigma^2 Z_n + mu^2 Z_n^2.

Existence of W. Put M_n = Z_n / mu^n. The first identity says that (M_n) is a nonnegative
martingale with respect to (F_n), and E[M_n] = E[M_0] = 1. A nonnegative martingale converges
almost surely, so W = lim M_n exists a.s. and is finite; by Fatou's lemma E[W] <= 1.

The mean of W. Taking expectations in the second identity, and using E[Z_n] = mu^n,

  E[Z_(n+1)^2] = sigma^2 mu^n + mu^2 E[Z_n^2].

Dividing by mu^(2n+2) gives E[M_(n+1)^2] = E[M_n^2] + sigma^2 mu^(-n-2), and since
E[M_0^2] = 1,

  E[M_n^2] = 1 + sigma^2 (mu^(-2) + mu^(-3) + ... + mu^(-n-1)) <= 1 + sigma^2 / (mu(mu - 1)),

using mu > 1 to sum the geometric series. So (M_n) is a martingale bounded in L^2. By the L^2
martingale convergence theorem, M_n -> W in L^2, hence in L^1, and therefore

  E[W] = lim E[M_n] = 1.

The same computation identifies the variance: E[W^2] = lim E[M_n^2] = 1 + sigma^2/(mu(mu-1)),
so Var(W) = sigma^2 / (mu^2 - mu). In particular W is not almost surely 0, and the event
{W > 0} has positive probability; on it, Z_n grows like W mu^n.
