- Fundamental theorem of calculus (Rudin, Principles of Mathematical Analysis, 3rd ed., Thm 6.20): let f be Riemann integrable on [a, b] and F(x) = integral from a to x of f(t) dt. Then F is continuous on [a, b]; and if f is continuous at a point x_0 of [a, b], then F is differentiable at x_0 and F'(x_0) = f(x_0).
- Riemann's criterion (Rudin, Thm 6.6): a bounded f is Riemann integrable on [a, b] if and only if for every epsilon > 0 there is a partition P of [a, b] with U(P, f) - L(P, f) < epsilon; equivalently, there are step functions s <= f <= t with integral of (t - s) < epsilon.
- Uniform limits and continuity at a point (Rudin, Thm 7.11): if f_n -> f uniformly on a set E, x is a limit point of E, and lim_{t -> x} f_n(t) = A_n for each n, then (A_n) converges and lim_{t -> x} f(t) = lim A_n.
