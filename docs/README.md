# init-math documentation

Start with the page for what you want to do.

**Using init-math**

- [README](../README.md): what init-math is, how to install it, and how to set up a
  project.
- [MODULES.md](MODULES.md): what a generated project contains, module by module, and when
  each part is on.
- Inside a generated project, `docs/OWNER.md` is the owner's manual: the decisions only
  you make, models and cost, and how to switch a part off or on.

**Installing on someone else's computer**

- [SETUP-GUIDE.md](../SETUP-GUIDE.md): the procedure an agent follows to walk a person
  through installation. It is written for the agent, but a person can read it too.

**Changing init-math**

- [ARCHITECTURE.md](ARCHITECTURE.md): how the interview, the answers file, the renderer and
  the harness adapters fit together, and the rules that hold for everything generated.
- [AUTHORING-MODULES.md](AUTHORING-MODULES.md): the format of a module, the template
  language, and the checks a module must pass.
- [TESTING.md](TESTING.md): the test suite, the behavioral scenarios, and the reviewer
  bench, which measures whether a reviewer catches real errors.
- [AGENTS.md](../AGENTS.md): the rules for working in this repository (for people and for
  agents).
